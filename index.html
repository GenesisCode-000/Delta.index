iOS

Sans jailbreak • Direct Install
1

Ouvrir le site & Onglet iOS

  • Ouvrez Safari (indispensable sur iPhone/iPad).
  • Allez sur deltaexploits.gg
  • Cliquez sur « ONGLET iOS ».
2

Direct Install (UNOFFICIAL)

  • Appuyez sur « Direct Install (UNOFFICIAL) ».
  • Une nouvelle fenêtre s'ouvre.
3

Deuxième clic

  • Nouvelle fenêtre : « Direct Install ».
  • Cliquez une seconde fois → téléchargement du profil.
✅ Dernière étape iOS :
Réglages → Général → VPN et gestion de l'appareil → installer le profil Delta → autoriser le certificat → redémarrer.

Android

APK officiel • Roblox moddé
1

Onglet Android

  • Ouvrez Chrome ou tout navigateur.
  • Rendez-vous sur deltaexploits.gg
  • Cliquez sur « ONGLET ANDROID ».
2

Télécharger l'APK

  • Appuyez sur « Download for Android ».
  • Le fichier .APK se télécharge.
  • Ouvrez les téléchargements et cliquez sur le fichier → Installer.
⚠️ CRUCIAL :
Avant de lancer Delta, désinstallez Roblox original (Paramètres → Applications → Roblox → Désinstaller). Sinon, conflit.
✅ Lancement :
Ouvrez Delta → Connectez-vous à Roblox → Profitez des scripts et exploits.
Questions fréquentes
🔹 Delta est-il sûr ?
Oui, des milliers d'utilisateurs l'utilisent quotidiennement. Téléchargez uniquement depuis deltaexploits.gg pour éviter les faux.
🔹 Pourquoi désinstaller Roblox original sur Android ?
Delta est une version modifiée de Roblox. Les deux ne peuvent pas coexister. Supprimez l'original puis installez Delta.
🔹 L'application ne s'ouvre pas après installation iOS ?
Vérifiez que vous avez bien autorisé le certificat dans Réglages → Général → VPN et gestion de l'appareil. Redémarrez votre iPhone.
🔹 Où trouver des scripts pour Delta ?
Rejoignez le serveur Discord officiel de Delta, il y a une section "scripts" avec des centaines de partages.
