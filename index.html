iOS Installation

No jailbreak required — direct install via Safari

iOS

Safari — Direct Install
1

Open deltaexploits.gg in Safari

ios-step1.png
  • Open Safari (required on iPhone/iPad).
  • Go to deltaexploits.gg
  • Tap on the iOS TAB button.
2

Tap "Direct Install (UNOFFICIAL)"

ios-step2.png
  • Tap Direct Install (UNOFFICIAL).
  • A new page will open automatically.
3

Click "Direct Install" Again

ios-step3.png
  • On the new page, tap Direct Install again.
  • The profile download will start.
Final Step: Settings > General > VPN & Device Management > Install Delta profile > Trust Certificate > Restart device.
